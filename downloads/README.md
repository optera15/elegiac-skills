## Recommended: all skills

**[Download Elegiac — All Skills](https://github.com/optera15/elegiac-skills/raw/refs/heads/main/downloads/elegiac-all-plugin.zip)**

Connect Elegiac and sign in, then start a fresh conversation. Choose the complete plugin or
smaller bundles, not both. For availability and manual connection, see the installation instructions.
