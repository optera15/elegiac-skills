# Model Routing Guide

How to choose a model. Names and limits drift — `list_models` is the live source of truth and `get_model_schema` is authoritative for parameters. This file tells you *how to choose*, not exact IDs.

## Image models

| Model family | Reach for it when | Watch out |
|---|---|---|
| **GPT Image 2.6** (`gpt-image-2-6`, the catalog default) | Rendered text (titles, posters, thumbnails, UI), graphic design, layout-heavy compositions, general high fidelity; strong reference-driven editing via `gpt-image-2-6-edit` (up to 9 references) | Default for any deliverable with words on it. Five quality rungs (low/medium/high/xhigh/max, default high); every input image is billed on edits. Override aspect presets with explicit width/height (e.g. 2400×1792 for 4:3 @2K) |
| **GPT Image 2.6 Flare** (`gpt-image-2-6-flare`) | The same model at roughly half the latency, same price | Pass it only when the user asks for speed or names Flare |
| **GPT Image 2** (`gpt-image-2`) | Legacy. Text-to-image only — its edit endpoint is retired and a referenced call is rejected | In the app it survives only in the Characters / Locations & Assets preview picker; prefer 2.6 everywhere |
| **Nano Banana 2.1** (`nano-banana-2-1`) | The fast default and board default: reference-driven work (character likeness from refs, restyles, composite-from-references, edits), strong in-image text and layouts; up to 14 references route to /edit (4 characters + 10 objects work best); 1k / 2k / 4k | Replaced Nano Banana 2. Billed on actual usage — the quote is the most it can cost and the unused part is refunded on completion. No 512px tier; no seed; panoramic 4:1 / 1:4 / 8:1 / 1:8 supported |
| **Nano Banana Pro / NB2 Lite** (`nano-banana-pro`, `nano-banana-2-lite`) | Pro: highest-fidelity Gemini portraits and grid layouts; Lite: the 1K fast text-to-image draft tier | Pro is slower and pricier; Lite is 1K only, and the app's editing surfaces now use MAI Image 2.7 in its place — prefer MAI Image 2.7 Flash or Nano Banana 2.1 for referenced drafts. Legacy `nano-banana-2` still runs when named, but prefer 2.1 |
| **MAI Image 2.7** (`mai-image-27`, `mai-image-27-flash`) | Microsoft's image model, when the user names it: text-to-image and edits with up to 5 references (`edit_image`, or `generate_image` with references), 1k or 2k, prompt used exactly as written. Pro (`mai-image-27`) is the higher-fidelity level; Flash (`mai-image-27-flash`) costs about a third as much | Billed on actual usage — the quote is the most it can cost and the unused part is refunded on completion; every reference adds to the quote. Nothing above 2k (4k renders 2k); 1k ultra-wide (21:9, 2.35:1) renders about 1.4 MP because each side is at least 768 px. No seed; PNG output |
| **Seedream 5.5** (`seedream-55`) | Stylized/editorial looks, fashion, bold color; multi-reference edits with up to 10 references (route to /edit); 2k (≈2.6 MP) or 4k (≈4.6 MP, its largest) | Every reference image adds to the price, the first included. Content policy is stricter on photoreal people refs. No seed; PNG output |
| **Seedream 5.0** (`seedream-50-pro`) | The previous Seedream, when the user names it | Prefer Seedream 5.5 — cheaper, and the app's editing surfaces now use it. Old `seedream-50-lite` ids resolve here |
| **Kling Image v4 / Kling O1 Image** (`kling-image-v4`, `kling-o1-image`) | Cinematic stills at 2K, 4K or 8K (one price at every size) with up to 10 reference images; O1 is reference-REQUIRED identity-preserving editing (up to 10 refs) | O1 has no text-to-image mode |
| **Grok Imagine 2.0** (`grok-imagine-2`) | Fast iteration with multi-reference editing up to 2K | Cheaper loose drafts; verify finals |
| **Muse Image** (`muse-image`) | Cheapest reference-capable stills (flat per image); accurate in-image text, plots and QR codes; 1–10 refs route to /edit | No seed or resolution control — Muse picks the size; no 4:5/5:4/2.35:1 |
| **FLUX.3 Image** (`flux-3-image`) | Black Forest Labs: layout-precise compositions and typography; 1–10-reference edits route to /edit-image (address refs as "image 1…image N" in order); 1k / 2k / 4k | A separate model from the **FLUX.3** video row below — never pass `flux-3` for an image. Priced per image by resolution: 4k is about 6× 2k and can take several minutes. No seed; JPEG output; no 2.35:1 (`auto` only on edits) |
| **MiniMax H3 Image** (`minimax-h3-image`) | MiniMax's image model, when the user names it: text-to-image at 2k or 4k with the prompt used exactly as written; 1–10 references route to its edit endpoint (`edit_image`, or `generate_image` with references), referred to as Image 1, Image 2, … in order | A separate model from the **MiniMax H3** video row below — never pass `minimax-h3` (or `h3`) for an image. Billed on actual usage — the quote is the most it can cost and the unused part is refunded on completion; every reference adds to the quote. A 4k edit needs an explicit aspect ratio (`auto` follows the first reference at 2k only). No seed; no 8k |
| **Grok Imagine Image** (`grok-imagine-t2i`) | Fastest cheap text-only drafts, exploration grids | Text-to-image only; not for finals |
| **Recraft V4** (`recraft-v4`) | Graphic design, vector-flavoured illustration, typography-friendly layouts | Text-to-image only (no refs) |
| **GPT 1.5** (`gpt-1-5`) | Transparent-background cutouts, quality-tiered stills | Text-to-image only |
| **Ideogram 4** (`ideogram-4`) | Heavy in-image text rendering | Agent surface runs the Fast tier only; hidden from the app UI since 2026-07 for safety-filter false positives on photoreal people — prefer GPT Image 2.6 / Recraft for text |

**Default routing:** text-on-image → GPT Image 2.6. Character continuity → Nano Banana 2.1 with cast refs. Stylized → Seedream 5.5. Identity-locked edits of an existing still → Kling O1 Image or Nano Banana Pro. Drafts → MAI Image 2.7 Flash, Nano Banana 2 Lite, Grok Imagine Image at 1K, or Muse Image (cheapest with references; also a good low-cost pick for text-on-image drafts).

## Video models

| Model family | Reach for it when | Watch out |
|---|---|---|
| **Veo 3.1** (`veo-3-1`) | Premium cinematic text-to-video, coherent physics, always-on native audio, first/last frame, reference images | Premium cost tier; use for hero shots |
| **Kling 3.0 Turbo** (`kling-3-turbo`) | Fast, cheaper Kling T2V/I2V with audio always on; `qualityTier` standard (720p) or pro (1080p); up to 6 storyboard shots via `multiPromptShots` (≤15s total) | No end frame, no references, 3-15s. Use it for iteration before stepping up to `kling-3` |
| **Kling 4.0** (`kling-4`; `kling 4`, `kling 4.0`, `kling-v4`) | 30 s single takes with native stereo audio and lip-synced dialogue (always on): text-, image- (first + optional last frame) and reference-to-video with up to 7 `elements` — characters/objects from images or one video, optionally bound to a saved voice via `voiceId` — plus up to 10 images and 5 reference videos (cited `@Image1` / `@Video1` / `@Element1`), multi-shot `multiPromptShots`, and video edit via `sourceVideoUrl` | NOT Kling 3.0 — never substitute either way. One tier; resolution is the only price axis (1080p default, 720p about a third less). Any video input bills input + output length at a lower rate, minimum 2× output — always more than the same clip without one — and asks the user first. Video inputs must be the user's own Elegiac media (upload_asset), MP4/MOV, 3-30 s (30 s combined); edits refuse sources over 30 s. No generateAudio, negative prompt, seed or audio references |
| **Kling 3.0 / Kling O3 / Kling O1** (`kling-3` — the catalog default, `kling-o3`, `kling-o1`) | Image-to-video animation of approved frames; reliable subject fidelity; accepts photoreal-person refs. `kling-3` takes `qualityTier` standard/pro/4k; O3 adds reference-to-video; O1 is the silent animate default with optional end frame | Kling V3 I2V rejects `aspect_ratio` — don't pass it. Tier up only when draft motion fails |
| **Seedance 2.0 Mini** (`seedance-2-mini`) | Default low-cost Draft video and animation, quick previz, cheap motion tests | 480p/720p only; use `qualityMode: "draft"` or `--quality-mode draft` when no model is explicit |
| **Seedance 2.0** (`seedance-2`) | Strong all-purpose motion, action beats, native audio; `qualityTier: "fast"` for the cheaper tier, Pro reaches 4K; `qualityTier: "us"` runs Pro on US-hosted inference (480p/720p, ~20% more) — only when the user explicitly asks for US hosting | Rejects photoreal-person reference images (content policy hides as a 422 on result) — use Kling when animating real-person likenesses |
| **Seedance 2.5** | Explicit-ask hero finish: native-audio T2V/I2V/R2V, quoted dialogue lip-sync, 4-30s takes at 480p/720p/1080p, start/end frames, and up to 50 multimodal refs (30 images / 10 videos / 10 audio). `qualityTier: "us"` runs it on US-hosted inference (480p/720p, same credits as Standard) — explicit ask only, not a quality upgrade | Very expensive, priced per second (1080p is ~2.5× the 720p rate; a 30s take costs 6× a 5s one — quote first). 1080p only on explicit ask. Video refs discount the rate but bill input seconds. Cite refs as `@Image1` / `@Video1` / `@Audio1`; never route here silently |
| **MiniMax H3** | Hero-tier 2K video with synchronized native audio (Hailuo-03): first/last keyframes, multimodal refs (9 images / 3 videos / 3 audio, cited as `@Image1`-style tokens). `qualityTier: "max"` runs H3 Max — the CHEAPER post-trained tier at 480p/768p with stronger prompt adherence; `qualityTier: "turbo"` runs H3 Max Turbo — half of Max again, text/image-to-video only (references are rejected, keep them on `max`) | Premium priced per second (extra image refs beyond 5 and ref-video seconds add cost); 2K only on standard, 5-15s. H3 Max is roughly 40% (480p) / 60% (768p) of the 2K rate on T2V/I2V, and reference-to-video bills the 768p rate at either resolution plus per-token reference charges; H3 Max Turbo is half the Max rate. Send `max` / `turbo` only on an explicit H3 Max / H3 Max Turbo ask, never for "max quality" language |
| **FLUX.3** | Shots driven by timed keyframes (up to 10 board/gallery images pinned to seconds — nothing else does this), first/last-frame interpolation, or extending an existing clip; native audio. `qualityTier: "max"` runs FLUX.3 Max — a post-trained variant with stronger prompt adherence and visual quality at the SAME price, on text/image-to-video, first/last frame and keyframes; optional `reasoningLevel` `high` (default) or `low` (faster, Max only) | Max has no extend and no draft (those stay on standard), and is not the H3 meaning of `max` (H3 Max is a cheaper lower-res tier) — send it only when the user asks for FLUX.3 Max. Premium priced per second (1080p is ~1.7× the 720p rate; extend is ~1.8-2.4× the per-second rate). Takes NO character/style reference images — describe subjects in the prompt. 5-20s. Extend sources must be 15s or under, and extend returns ONLY the new footage (not the source with the extension appended) |
| **LTX-2.5** | The economy native-audio option: cheap iteration WITH sound, first→last-frame transitions on a budget, multi-shot prose (2-4 cuts described in one prompt, total locked to 10s), and audio-to-video — pass one audio clip and the output follows it, a cheap way to turn a still plus a voice track into a talking clip (OmniHuman 2 via `generate_lipsync` is the dedicated avatar route) | Two tiers that both render 720p/1080p, so the tier is never inferred from the resolution: Fast (default, priced per second and rising with resolution, 6-20s even durations, reaches 1440p/2160p) and Pro (about a third more per second, capped at 10s and 1080p). Takes NO character/style reference images. Audio-to-video is billed per second of the INPUT clip and needs its measured length declared (`audioDurationSeconds`) — 2-20s on Fast, 2-10s on Pro |
| **Boreal** (`creatify-boreal`; `boreal`, `creatify`) | The cheapest clip in the catalog that has speech: native voice, synchronized sound and legible on-screen text from one prompt, any whole second 1-20s at 720p/1080p/2K. The pick for UGC, product, presenter and ad spots, for on-screen text, and for any cheap/fast/draft-with-sound ask. Takes one optional reference image to animate and one optional audio clip that supplies the narration | Priced per second: 1080p is ~3× and 2K ~12× the 720p rate (`2k` is 2016px on the long edge — not 1440p, not 4K). Prompts are FOUR ordered sections — `[VISUAL]` / `[SPEECH]` / `[SOUNDS]` / `[TEXT]` — every one present, dialogue in double quotes, about 2 words of speech per second. An attached clip is CUT to the duration you set and never changes the length or the price (the opposite of LTX-2.5 audio-to-video), so no measured length is needed. NO multi-reference mode and no end frame. Weakest on close-up talking-head lip-sync — route those to OmniHuman 2 via `generate_lipsync` |
| **WAN 3.0** (`wan-3`; `wan3`, `wan 3.0`, `alibaba wan`) | Long native-audio takes: any integer 2-30s at 480p/720p/1080p on T2V/I2V/R2V, first+last frames, and up to 20 multimodal refs (10 images / 5 videos / 5 audio, cited as `@Image1` / `@Video1` / `@Audio1`). Multi-shot is prose in ONE prompt — up to 6 cuts distributed across a 30s take, no shots array. The pick when the ask is a long clip WITH sound, or a reference set that includes video or audio | Two tiers that both render every resolution, so the tier is never inferred from it: Standard (default; the per-second rate doubles at each step from 480p to 720p to 1080p) and Prime (roughly 1.4x). Unlike the other multi-ref heroes, Standard needs NO explicit ask — but Prime does. Cost is linear in length: 30s at Prime 1080p costs ~17× a 5s Standard 720p take, so quote before committing to long or 1080p takes. Reference video and reference audio are each capped at 15s combined |
| **Luma Ray 3.2** (`luma-ray-3-2`) | Silent cinematic T2V in wide formats (21:9, 4:3, 3:4 …) and start→end-frame transitions; 540p is its cheapest rung | No audio, no references; 5 or 10s (I2V is always 5s); 1080p costs 4× 540p (8× on I2V) |
| **Gemini Omni Flash 1.2** (`gemini-omni-flash`) | 3-15s clip with generated audio at 360p-4K, from text, a start image (optional end frame), or up to 10 image + 3 video references (each up to 15s) | 3-15s (default 8; at most 10s with `endImageUrl`), 360p/720p/1080p/4k (default 720p), 16:9 or 9:16. Editing, extending and upscaling a video are in the Elegiac app only — agent calls with `sourceVideoUrl` are refused |
| **Pixverse C1** (`pixverse-c1`) | Transitions between two frames, reference-to-video, optional audio at 720p/1080p | Mid-priced; pick `qualityTier` 720p for drafts |
| **Happy Horse** (`happy-horse`) | Cheap T2V/I2V/R2V with a built-in safety checker | Conservative filter — expect rejections on edgy content |
| **Grok Imagine 1.5 Video** (`grok-imagine-video-1-5`; bare `grok-imagine` resolves here) | Multi-reference reference-to-video with always-on audio | R2V caps at 720p. The 1.0 model (`grok-imagine-video`) is legacy — reachable by explicit id only |

**Default routing:** animating an approved frame for professional output → Kling or another schema-supported start-image model. Text-to-video hero → Veo. Drafts/previz → `qualityMode: "draft"` so Elegiac routes omitted video models to Seedance 2.0 Mini at 5s/480p. Keep iteration on Mini; use Seedance 2.5 only when explicitly requested for a native-audio 30s hero finish or its high-capacity multimodal reference workflow. Silent drafts stay on Mini, but when the iteration needs sound, Boreal at 720p is the cheapest rung that has speech at all and the right default for UGC/product/presenter spots and anything with on-screen text; LTX-2.5 Fast is the next pass up when the shot needs its longer takes, higher resolutions or a first→last transition — and LTX-2.5 Pro at 10s or under is a reasonable finish when the shot does not need a hero model. Past LTX-2.5's 20s ceiling — or when the reference set contains video or audio — WAN 3.0 Standard is the mid-cost long-take option and does not need to be asked for by name; save `qualityTier: "prime"` for when the user says Prime.

Not on the agent surface (app-only, do not route here): LTX-2.3, WAN 2.2/2.6 (the older WAN families — WAN 3.0 above IS routable, and a bare "WAN" resolves to none of them), Hailuo 2.3, Pixverse V6, Vidu, Kling Avatar, Topaz/SeedVR upscalers. `list_models` is authoritative if this drifts.

## Cost discipline

- Cost scales with resolution (stills) and duration × resolution (video; priced per second). Quote with `quote_generation` before batches.
- Ladder: explore at 1K stills / 5s Seedance 2.0 Mini 480p video drafts (`qualityMode: "draft"`) → upgrade only the keepers to 2K / 720p+ / longer takes. When the draft has to carry audio, Boreal 720p is the cheapest rung that has speech, and LTX-2.5 Fast is the next one up.
- Never re-roll a failed look more than twice on the same model — change the prompt structure (see `prompt-patterns.md`) or switch families.
