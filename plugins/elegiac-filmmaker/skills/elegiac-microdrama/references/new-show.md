# Create a new microdrama series

1. Interpret the premise as protagonist + desire + obstacle + contradiction + renewable relationship/story engine. Ask only missing decisions that materially affect the result: look, locale/rating, season length, control profile, existing cast/voices, intended audience and branding. Default episodes to 60–90 seconds, ideally 75 total. Retain the 60-episode season option without forcing it on an existing show.
2. Offer a compact concept round when useful; a supplied approved premise does not need reinvention. Lock title, logline, promise, theme and why Episode 2 matters. Read craft.md.
3. Inspect existing Productions before creating one tagged microdrama. Reuse or create 00 — Series Bible. Store canon, relationships, secrets, voice IDs, recurring locations/props, look and season spine in series-manifest.json and matching Board artifacts. Never use Showrunner.
4. Plan the season in text with per-episode hook/turn/cliffhanger and opens/advances/resolves. Produce only one episode at a time; do not generate future episode media from a season request by default.
5. Reuse Cast records before creating characters. Where needed, use character concept -> create_character_on_board -> make_board_character_consistent -> promote_character_concept with the EXISTING castMemberId. Check current tool schemas. Do not create a second Cast member by promoting without the link ID. Inspect multi-view sheets for complete, consistent identity, wardrobe and readable hands; retain source IDs and rights.
6. Assign an ElevenLabs Voice ID to every speaking role before that role's first scene. Generate/audition expressive solo samples using production-pipeline.md; no need to generate all season dialogue now.
7. Reuse inspected location assets. For a missing recurring location, establish one approved spacious master (normally full-bleed 16:9), geographical rules and light. Add only essential unseen geometry/prop/vehicle anchors. No mandatory reverse-angle coverage set or still per cut.
8. Resolve/reuse a compact branding package using branding.md. It is part of the total runtime budget, not an unbudgeted intro.
9. Create one titled Episode Board and version 2 blueprint. Follow new-episode.md: scenelet plan -> references/voice samples -> one representative WAN native-audio scenelet -> review -> remaining episode -> light assembly. Preserve scoped authorizations and user-selected checkpoints.
10. Deliver through edit.md and qa.md, update canon/loops and propose the next episode without starting it automatically.

Fast Track shows a concise series promise, principals/look, movement map and Episode 1 plan. Co-Creator reviews structural choices; Director retains department checkpoints. All profiles keep technical checks and real permission boundaries. An instruction to finish autonomously carries through the authorized episode.
